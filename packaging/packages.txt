# ramstein — runtime dependencies
#
# Pure Python standard library — no pip/PyPI dependencies at all. Everything
# below is an EXTERNAL BINARY ramsteind/ramstein/ramstein-update shells out
# to, split hard (packaging/deb's Depends, dpkg pulls it in automatically) vs
# optional (feature degrades gracefully if absent).

# --- hard (make deb's Depends) ---------------------------------------------
python3 (>= 3.8)  # the interpreter itself
systemd         # ramsteind.service, ramstein-update.timer,
                # ramstein-autocalm.timer, `systemctl is-active` (the
                # systemd-oomd/earlyoom coexistence check)
openssh-client  # `ssh-keygen -Y verify`: ramstein-update's release-signature
                # check against release-signing/allowed_signers (Wave B,
                # docs/RELEASE-SIGNING.md). Absent: sutra_update.py's
                # verify_dir() fails closed (refuses to install) rather than
                # crashing.

# --- optional (make deb's Suggests, never Recommends) -----------------------
# Operator ruling 2cd900ce, family-wide: NOTHING AUTO-PULLS. apt installs
# Recommends by default -- a headless install must never pull GNOME in behind
# it, so every optional package here is Suggests, which apt never installs
# unasked. Anything actually missing is named, with the install command, in
# the verb's own refusal -- not silence, not a crash.
gnome-shell     # the Quick Settings pill (extension/ramstein@asuramaya).
                # Absent: ramsteind and the `ramstein` CLI work exactly the
                # same headless; only the GNOME UI is unavailable.
systemd-zram-generator  # `ramstein zram enable`. Backs ONE opt-in layer-3
                # verb, not a subsystem every user touches -- a hard Depends
                # would put a boot-time systemd generator on every install to
                # avoid a message the verb already gives for free. Absent:
                # `zram status`/`enable` refuse with "systemd-zram-generator
                # is not installed (apt install systemd-zram-generator)";
                # every other verb is unaffected.
